Product design & build · 2026

Only the props worth a look.

A player-prop board that hides everything that doesn't clear the bar. Designed, built and run by me — live at propr.win.

Role
Design, front end, model
Stack
React, Tailwind, FastAPI
Benchmarked
Linemate, sportsbooks
Status
Live, invite-only

Every demo here is the real component, rebuilt from Propr's source. Sample slate.

Thinking

From noise to a short list

Problem

Books list hundreds of props a game. Research means three other tabs.

Benchmark

Linemate shows trends but lists everything. Books are fast but never say "skip this".

Insight

Bettors don't need more data. They need the noise cut.

Bet

Projection, price and recent games on one row. Hide the rest.

How might a bettor see tonight's few worthwhile props — and know the second news changes one?

01 · Board UI

Two views, one board

Analytical is a workstation: filters, news and a detail panel around the board. Basic is one column: pills on top, the last 10 games drawn out.

  • Entrance
    Rows fade up one after another
  • Select
    Row lights up, detail panel follows
  • Switch
    Pill slides to the new view
02 · Skeleton loading

The logo draws while the board builds

No spinner. The mark draws its trend line; skeleton rows hold the layout so nothing jumps.

  • Logo
    Line draws, then the arrowhead
  • Shimmer
    A steady sweep, no easing
  • Rows
    Each placeholder a little fainter
  • Hand-off
    Placeholders fade, rows rise in place
Loading state
03 · Dynamic game bar

Tonight's slate on a slow belt

Too many games to fit? It scrolls itself. Hover to stop. Click to filter.

  • Speed
    More games, slower belt
  • Control
    Pauses on hover and focus; Static in Settings
Hover to pause, click a game
04 · Lineup alerts

News can't wait for a refresh

Ranked by impact: ruled out first. "View props" jumps to the rows it touches.

  • Enter
    Slides in from the edge
  • Signal
    One ping, colour by severity
  • Life
    Draining bar, hover pauses
  • Stack
    Three at most, the rest fold away
Send news
05 · Dynamic line adjustment

Move the line, the pick re-prices

Curve, bars, chance, price and value all follow. Off a posted line, odds become a labelled fair price.

  • Line mark
    Slides, never jumps
  • Bars
    Recolour as the line moves
  • Numbers
    Count up to the new value
  • Confirm
    Tick draws once
Drag, step, flip to Under
06 · Sign-in with two-step email

Invite-only, without the friction

Password or Google, then a code by email every time. Access code on first sign-in only. The code field auto-submits at six digits.
